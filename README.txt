Lightning Lab 6.1 · 闪电特效工作室

使用方法
1. 解压 ZIP，用最新版 Chrome 或 Edge 打开 index.html 即可使用。
2. 如需部署到原 GitHub Pages，将 index.html 上传到 lightning-lab 仓库根目录，覆盖旧文件即可。
3. 无需登录或安装依赖；导入的素材只在当前浏览器处理。

动态背景
- 左侧「背景素材」导入 PNG、JPG、WEBP 或 MP4。动态 WEBP 和 MP4 可在画布里跟随播放按钮播放；没有闪电路径时也能预览背景。
- MP4 默认静音循环，时间轴拖动可定位视频画面。建议使用 H.264 编码的 MP4。
- 动态 WEBP 在新版 Chrome / Edge 中使用逐帧解码，时间轴和导出均按帧定位；其他浏览器尝试以浏览器自身的动画播放预览，逐帧导出动态背景需要 ImageDecoder 支持。
- 调整背景透明度及适配方式；删除背景不影响路径。导入背景不会改变画布尺寸或路径大小。
- 背景默认仅作绘制参考。若要合成在 PNG 序列帧或动画 WEBP 里，勾选「导出时包含背景」。MP4 素材作为背景参与合成，网站不输出 MP4 文件。

其他功能
- 固定画布，全区域绘制；节点与方向手柄编辑。
- 新建与续画闪电、插入节点、闭合路径、撤销与重做。
- 正向 / 反向、闭合路径顺 / 逆时针、往返及随机游走。
- 单帧 PNG、PNG 序列 ZIP、动画 WEBP 导出与质量设置。

本次更新
- 选择「高频闪烁」后可调闪烁频率，范围随 FPS 自动变化，避免低帧率下显示失真。
- 随机断裂每隔数帧独立生成；首端、中间、尾端都可能断开，断裂数量、位置与长度的变化幅度更大。

节点快调（6.1）
- 选择任意闪电后，左侧节点快调列表显示该路径的每个节点。点编号定位；X/Y 输入框可直接修改坐标，不限制在画布内部。
- 每个节点均可独立删除，包括首尾节点和最后一个节点；路径不足 2 点时保持为未完成状态，可继续添加，Ctrl+Z 可撤销。
- 画布编辑模式下拖动节点和方向手柄；选中节点后方向键每次微调 1 px，Shift+方向键 10 px，Delete / Backspace 删除。
