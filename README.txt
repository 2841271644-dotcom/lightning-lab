Lightning Lab 5.8 · 闪电特效工作室
深蓝配色完整版

使用方法
1. 解压 ZIP，用 Chrome 或 Edge 打开 index.html 即可使用。
2. 部署到网站时，将 index.html 放入网站目录，即可直接访问。
3. 页面无需登录，无需安装依赖或配置后端。

功能
- 固定画布，全区域绘制；节点与方向手柄编辑。
- 新建闪电与续画选中明确区分，可从起点或终点延伸。
- 支持沿原曲线添加节点、闭合路径、撤销与重做。
- 正向 / 反向、闭合路径顺 / 逆时针、往返及随机游走。
- PNG、WEBP、JPG 背景参考图导入、删除及透明度调整。
- 单帧 PNG、PNG 序列 ZIP、动画 WEBP 导出与质量设置。

素材和图像编码均在当前浏览器本地处理。
背景参考图默认不随闪电导出，可勾选“导出时包含背景”。
